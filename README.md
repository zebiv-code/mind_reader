# Mind Reader

Interactive mind-reading card trick. Pick a card mentally, and watch it disappear from the pile. The secret? All cards are swapped — but you'll only notice yours is gone.

**[Live Demo](https://zebiv.com/mind-reader/)**

## Tech

- Vanilla HTML/CSS/JavaScript
- CSS card animations with 3D transforms
- Card images from Deck of Cards API
